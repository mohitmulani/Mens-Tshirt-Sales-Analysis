# Men's T-Shirt Sales Analysis | Power BI

## Project Overview

This project focuses on analysing men's T-shirt product and pricing data using Microsoft Power BI. The objective is to explore product brands, original prices, discounted prices, and pricing patterns to generate meaningful business insights.

The project demonstrates practical data analytics and business intelligence skills through data exploration, price analysis, and interactive visualisation.

## Tools & Technologies

- **Microsoft Power BI** – Data visualisation and dashboard development
- **CSV** – Dataset storage and source data

## Dataset Description

The project uses a dataset containing men's T-shirt product information.

**Dataset:** `Men Tshirt.csv`

**Records:** 1,444

| Column | Description |
|---|---|
| Brand | Brand associated with the product |
| Title | Product name or description |
| Original Price | Listed original product price |
| Sale Price | Discounted selling price |

## Project Objectives

- Analyse product distribution across different brands.
- Explore original and discounted product prices.
- Compare original prices against sale prices.
- Understand discounting patterns across products.
- Identify pricing trends that can support business decisions.
